# AI без воды — автопилот Telegram-канала

Канал [@ai_bez_vody_ru](https://t.me/ai_bez_vody_ru) про нейросети и AI-инструменты
для русскоязычной аудитории. Посты пишутся и публикуются полностью автоматически —
без участия владельца и без включённого компьютера.

Этот файл — актуальное состояние проекта. Правила ведения канала лежат в
[CLAUDE.md](CLAUDE.md), ниша и рубрики — в [CONTENT_PLAN.md](CONTENT_PLAN.md).

## Как это работает

Всё крутится на GitHub Actions, домашний компьютер и токены Claude не нужны:

1. **Каждый день в 19:00 МСК** [daily-post.yml](.github/workflows/daily-post.yml)
   запускает `scripts/gemini-post.py`.
2. Скрипт собирает свежие материалы из RSS-лент (TechCrunch, The Verge, Ars
   Technica, блоги OpenAI и Google, Hugging Face, Хабр, Google News) — с точными
   датами публикации.
3. **Gemini** (бесплатный тариф) пишет пост по правилам из
   [prompts/gemini-post.md](prompts/gemini-post.md), сверяясь с 14 прошлыми постами
   в `archive/`, чтобы не повторяться. Скрипт проверяет ответ и при ошибке просит
   Gemini исправить.
4. Рисуется фирменная карточка, пост уходит в канал, `posted-log.md` и `archive/`
   пополняются.

Почему RSS, а не поиск внутри Gemini: у бесплатного тарифа квота на поиск и на
картинки нулевая. Ленты заодно не дают подать старую новость как свежую — даты
берутся из ленты, а не на веру модели.

Ручной запуск: закоммитить файл `trigger/daily-post` (со словом `dry` — без
публикации). Разовый пост с готовым текстом — через `queue/post.json`, его
публикует [publish.yml](.github/workflows/publish.yml).

До 2026-09-23 посты писал облачный агент Claude — отключён, чтобы не тратить
токены Claude.

## Структура

```
CLAUDE.md          — правила ведения канала для автономного агента
CONTENT_PLAN.md    — обоснование ниши, рубрики по дням, шаблон поста, монетизация
posted-log.md      — журнал публикаций, ведёт GitHub Actions
archive/           — полные тексты вышедших постов, по ним Gemini избегает повторов
prompts/
  gemini-post.md         — правила и шаблоны для Gemini
trigger/daily-post — коммит сюда запускает ежедневный workflow вручную
queue/post.json    — ручная очередь, исчезает после публикации
scripts/
  gemini-post.py         — ежедневный пост: RSS → Gemini → карточка → Telegram
  publish-from-queue.py  — публикация из ручной очереди
  generate-card.py       — карточка поста (Pillow)
  generate-card.ps1      — то же для локального предпросмотра на Windows
  generate-avatar.ps1    — аватар канала
  push-to-github.ps1     — заливка локальных файлов в репозиторий без git
```

## Секреты

- Токен бота — секрет репозитория `TELEGRAM_BOT_TOKEN` (Settings → Secrets and
  variables → Actions). В коде и в очереди его нет.
- Ключ Gemini — секрет `GEMINI_API_KEY`. Нужны оба секрета одновременно.
- Локальные копии (`config/config.json`, `config/github_token.txt`) лежат только
  на машине владельца и закрыты `.gitignore`.

## Что осталось

- Привлечение подписчиков: сначала накопить 15–20 постов, затем кросспостинг
  (vc.ru, Habr, DTF), взаимопиар, посевы. Бюджет не определён.
- Через 4–6 недель — посмотреть метрики и перебалансировать рубрики.
