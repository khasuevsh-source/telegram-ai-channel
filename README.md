# AI-канал в Telegram — автопилот

Канал про нейросети и AI-инструменты для русскоязычной аудитории. Контент план,
обоснование ниши и правила ведения — в [CONTENT_PLAN.md](CONTENT_PLAN.md) и
[CLAUDE.md](CLAUDE.md).

## Что нужно сделать вручную (это может только владелец аккаунта)

### 1. Создать канал
В Telegram: **New Channel** → вставить название и описание ниже (или свои) →
сделать канал публичным и задать короткий @username (без этого проще постить,
chat_id не нужен).

**Название:** `AI без воды`
(запасные варианты, если вдруг не понравится: «Нейросети по делу», «Испытано
нейросетью», «Кнопка AI», «AI-сосед»)

**Описание (копировать как есть):**
```
Нейросети и AI-инструменты без хайпа: что вышло, как этим пользоваться и стоит
ли того. Коротко, по делу, с честными минусами.
```

**@username:** `ai_bez_vody_ru`

### 2. Создать бота
Написать **@BotFather** → `/newbot` → задать имя и username (должен заканчиваться
на `bot`) → BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxx`.

### 3. Добавить бота администратором канала
Канал → Administrators → Add Admin → найти своего бота → включить право
**Post Messages**.

### 4. Передать доступы
Скопировать `config/config.example.json` в `config/config.json` и вписать туда
токен бота и @username канала. Можно сделать это самостоятельно в файле, либо
прислать токен и username в чат — я впишу сам.

## Что после этого делаю я

1. Проверяю подключение (тестовый пост).
2. Настраиваю автозапуск по расписанию (1 пост в день, до этого — можно чаще на
   старте), который сам находит повод, пишет пост по плану из CONTENT_PLAN.md и
   публикует его через `scripts/send-telegram-post.ps1` — без обращения к вам за
   подтверждением каждого поста (так и было согласовано).
3. Веду `posted-log.md`, чтобы не повторяться, и раз в несколько недель могу
   предложить корректировку стратегии по факту метрик.

## Структура проекта

```
CLAUDE.md               — правила ведения канала для автономного агента
CONTENT_PLAN.md          — ниша, рубрики, шаблон поста, дорожная карта монетизации
posted-log.md            — журнал публикаций
config/config.example.json — шаблон конфига (скопировать в config.json)
scripts/send-telegram-post.ps1 — публикация поста через Bot API
```

`config/config.json` — секрет, никуда не публикуется и не коммитится.
