# AI без воды — автопилот Telegram-канала

Канал [@ai_bez_vody_ru](https://t.me/ai_bez_vody_ru) про нейросети и AI-инструменты
для русскоязычной аудитории. Посты пишутся и публикуются полностью автоматически —
без участия владельца и без включённого компьютера.

Этот файл — актуальное состояние проекта. Правила ведения канала лежат в
[CLAUDE.md](CLAUDE.md), ниша и рубрики — в [CONTENT_PLAN.md](CONTENT_PLAN.md).

## Как это работает

Три звена, ни одно не зависит от домашнего компьютера:

1. **Облачный агент Claude** (routine, ежедневно в 19:00 МСК / 16:00 UTC) читает
   CLAUDE.md и CONTENT_PLAN.md, определяет рубрику по дню недели, ищет свежий повод
   через веб-поиск, пишет пост и коммитит его в `queue/post.json`.
2. **GitHub Actions** ([publish.yml](.github/workflows/publish.yml)) срабатывает на
   этот коммит: `scripts/publish-from-queue.py` рисует карточку, отправляет пост
   в канал через Bot API и дописывает строку в `posted-log.md`.
3. **Telegram** показывает пост подписчикам; реакции и комментарии включены.

Прямой постинг из облачной песочницы Claude невозможен — её egress-политика
блокирует `api.telegram.org` (`CONNECT tunnel failed, 403`). Поэтому отправкой
занимается GitHub Actions, где сеть не ограничена.

### Защита от дублей

Публикация захватывается в git до отправки: прогон удаляет `queue/post.json`,
коммитит и пушит — и только если push прошёл, отправляет пост. Параллельный прогон
получает отказ при push и выходит, ничего не отправив. Появилось после инцидента
2026-09-18, когда один пуш породил два прогона workflow и пост ушёл дважды.

## Структура

```
CLAUDE.md          — правила ведения канала для автономного агента
CONTENT_PLAN.md    — обоснование ниши, рубрики по дням, шаблон поста, монетизация
posted-log.md      — журнал публикаций, ведёт GitHub Actions
queue/post.json    — очередь: появляется от агента, исчезает после публикации
scripts/
  publish-from-queue.py  — публикация из очереди (запускается в Actions)
  generate-card.py       — карточка поста (Pillow)
  generate-card.ps1      — то же для локального предпросмотра на Windows
  generate-avatar.ps1    — аватар канала
  push-to-github.ps1     — заливка локальных файлов в репозиторий без git
```

## Секреты

- Токен бота — секрет репозитория `TELEGRAM_BOT_TOKEN` (Settings → Secrets and
  variables → Actions). В коде и в очереди его нет.
- Право записи для облачного агента — через установленное на репозиторий
  приложение Claude на GitHub, без токенов в конфигах.
- Локальные копии (`config/config.json`, `config/github_token.txt`) лежат только
  на машине владельца и закрыты `.gitignore`.

## Что осталось

- Привлечение подписчиков: сначала накопить 15–20 постов, затем кросспостинг
  (vc.ru, Habr, DTF), взаимопиар, посевы. Бюджет не определён.
- Через 4–6 недель — посмотреть метрики и перебалансировать рубрики.
